## 4. Rules clarifications
- **Panikmarker rule card** [46:34] (High):
  - Close to verbatim: "Erhältst du einen Panikmarker, lege ihn auf deine Heldenkarte. Hast du einen oder mehr Panikmarker, darfst du Handkarten nur noch **zufällig** spielen. Möchtest du eine Handkarte spielen, mische deine Handkarten, ziehe eine zufällig und spiele sie. Lege nach dem Spielen der Karte sofort **einen** Panikmarker ab. Du darfst weiterhin Gegenstände deiner Wahl nutzen. Panikmarker beeinflussen dies nicht."
  - Ways to remove them: Medizintasche (2 status markers), Omas Helm (remove 2 status markers if ≥15 HP), Rauchbombe.
  - Panic markers stay across rounds.
- **Actions** (High):
  - Each hero has **3 actions per round** ("eine von drei Aktionen" [159:23]).
  - Using an item is an action. Drawing 1 card is an action ("mit einer Aktion eine Karte ziehen" [89:12]).
  - You cannot freely discard during a round; Ben had to play a card just to get rid of it [176:36].
- **Verstärkung** (High): it needs an earlier attack of the same type this round, otherwise it is wasted.
  - Arkanes Monokel "ist wirkungslos, da noch kein Angriff desselben Schaden(styps)" [80:15].
  - They complain that the action is still used up [158:03, 262:20].
- **Hand size and end of round:**
  - (Medium) Hand size is the number you draw up to at the end of a round, not a maximum during the round [66:28]. But a "Handkartenlimit ... muss ich abwerfen" is mentioned at [135:00].
  - At the end of a round: discard played cards plus any hand cards you choose, then draw up.
  - Mulligan: not settled.
- **Ritterlicher Beistand** (High):
  - Text: "Die Bossattacke, die dich aktuell bedroht, entfällt. Lenke stattdessen eine Bossattacke, die einen anderen Helden bedroht, auf dich um."
  - App/editor: it only works if you are currently threatened. With 0 threat it does nothing.
